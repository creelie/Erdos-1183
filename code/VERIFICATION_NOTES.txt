Checks behind the computational and formal claims of
"Resolution of the Erdos-Ulam conjectures on monochromatic union-closed
families"
(September 2026)
=====================================================================

1. brute_small.py (no SAT solver) reproduces f(n) = F(n) = 1, 2, 2, 3 for
   n = 1, 2, 3, 4.

2. Every witness file (witness_f_3.txt to witness_f_9.txt,
   witness_F_3.txt to witness_F_7.txt) was re-checked with the
   independent SAT encoding in witnesses.py for the values of Table 1:
     f(3..9) = 2, 3, 3, 4, 4, 5, 5   and   F(3..7) = 2, 3, 4, 5, 7.
   Both colour classes pass for every n.

3. The cardinality colourings g_3, ..., g_10 printed in the paper were
   checked with the same encoding (verify_g.py): none has a monochromatic
   sublattice with more than ceil((n+1)/2) members.  Re-running the
   restricted search (sizebased.py) for n = 8, 9 returns exactly g_8 and
   g_9 as printed; f_card_search_sat.py returns g_10 for n = 10.

4. The lower bounds F(5) >= 4, F(6) >= 5 and F(7) >= 7 were recomputed
   with small_values.py, asserting for every family behind an added
   clause that it is union-closed, has at least m members and lies in
   one colour class.  Clause counts: 62, 6148 and 256428 (F(7) took
   951 s on one core).  These bounds depend only on the final UNSAT
   verdict of CaDiCaL.

5. The Lean project in ../lean (Lean 4.34.1, Mathlib v4.34.1) was rebuilt
   from source, and each file was re-elaborated directly with
   `lake env lean`; there are no errors, warnings or `sorry`.  Check.lean
   reports that erdos_1183 and the other main theorems use only propext,
   Classical.choice and Quot.sound.

6. Bibliography entries were checked against Crossref or the publisher's
   records (authors, title, venue, volume, pages, DOI).  Erdos's 1978
   paper, in which the problem first appeared, could not be checked
   online and is therefore not cited; the problem is cited through
   erdosproblems.com instead.
